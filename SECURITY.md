# Security Policy

## Supported versions

The project currently supports the latest main branch and the most recent release
available in the repository.

## Reporting a vulnerability

If you discover a security issue, please do not open a public GitHub issue.
Instead, report it privately by contacting the maintainer through the GitHub
security advisory system or the repository owner contact method.

Please include:

- A clear description of the vulnerability
- Steps to reproduce it, if possible
- Affected files, routes, or components
- Any proposed mitigation or fix

We will review the report as quickly as possible and keep you informed about the
status of the fix.

## Response expectations

We aim to acknowledge valid reports promptly and work toward a fix in a timely
manner. Depending on the severity, a public advisory may be published after the
issue is resolved.

## Scope

This policy applies to security vulnerabilities in the application, backend API,
AI processing logic, authentication flows, document handling, and local runtime
configuration used by the project.
